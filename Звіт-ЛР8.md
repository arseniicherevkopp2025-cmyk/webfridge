## Виконання роботи

Стару стартову версію `before/` виключено з публікації; локальні секрети, залежності та системні файли додано до `.gitignore`.

### Git

Локальний репозиторій створено у гілці `main`; налаштовано remote `origin`. До GitHub передано 83 файли проєкту окремими логічними комітами. Віддалена історія містить 12 змістовних комітів; останній — `09b05c0` (`docs: add project demonstration screenshots`).

Після синхронізації локальна гілка `main` відповідає `origin/main`, робоча директорія чиста. Скріншот сторінки комітів GitHub використовується як візуальне підтвердження віддаленої історії.

### GitHub

**Публічний репозиторій:** https://github.com/arseniicherevkopp2025-cmyk/webfridge  
**Стан репозиторію:** публічний; усі 83 потрібні файли проєкту завантажені, а історія комітів перевірена у браузері. Передавання виконано через GitHub web UI після того, як користувач дозволив розширенню Chrome доступ до локальних файлів. Git push через Git Credential Manager окремо не спрацював у середовищі.

У репозиторії є README.md, `.gitignore`, `.nojekyll`, `netlify.toml`, статичні сторінки сайту, ресурси та скриншоти. Робоча папка `before/` до публічного репозиторію не входить.

### Розгортання

У GitHub Pages обрано `Deploy from a branch`, гілку `main` і кореневу папку `/`; GitHub Actions збірка Pages завершилася успішно. На Netlify сайт опубліковано через Netlify Drop з ZIP-архіву; доступ до production-сайту встановлено як Public. Інтеграцію Netlify з GitHub не вдалося ввімкнути через недоступну кнопку авторизації, тож автоматичне розгортання після наступних комітів не налаштовано.
