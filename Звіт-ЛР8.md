## Виконання роботи

В основу взято статичний багатосторінковий сайт лабораторної №7. У ньому є головна сторінка, сторінки рецептів і продуктів, стани інтерфейсу та каталоги з CSS, JavaScript, медіа й скриншотами. Стару стартову версію `before/` виключено з публікації; локальні секрети, залежності та системні файли додано до `.gitignore`.

### Git

Локальний репозиторій створено у гілці `main`; налаштовано remote `origin`. Історія містить три змістовні коміти:

- `8c8eea9` — `feat: import student fridge website from lab 7`
- `1ef79ea` — `chore: add project guide and hosting config`
- `a781c89` — `docs: add lab 8 report and prompt log`

Скріншот `git status` / `git log --oneline` у VS Code ще потрібно додати.

### GitHub

**Публічний репозиторій:** https://github.com/arseniicherevkopp2025-cmyk/webfridge  
**Стан репозиторію:** публічний і порожній; це перевірено у браузері.  
**Стан push:** коміти поки залишаються локальними. Git Credential Manager не зміг завершити авторизацію через TLS/сховище облікових даних у середовищі. Завантаження через браузер також очікує ручного ввімкнення доступу розширення Chrome до локальних файлів.

### Розгортання

Netlify налаштовано на публікацію статичних файлів із кореневої папки через `netlify.toml`. Для GitHub Pages передбачено розгортання вмісту гілки `main` із кореневої папки. Ці параметри ще не застосовано, бо файли не передано до віддаленої гілки.

**GitHub Pages URL:** додати після активації Pages.  
**Netlify URL:** додати після розгортання.

## Висновок

Підготовлено локальний Git-репозиторій із трьома змістовними комітами, README і конфігурацією для статичного хостингу. Для завершення залишилося передати `main` до GitHub, увімкнути GitHub Pages, під’єднати репозиторій у Netlify та внести фактичні URL і скриншоти до звіту.
