# Лабораторна №5 — Холодильник студента, V2

## Як запустити

1. Розпакуй ZIP повністю. Не відкривай сайт усередині архіву.
2. У VS Code: File → Open Folder → вибери папку `lab-05-v2`.
3. Відкрий `index.html`.
4. Натисни правою кнопкою в редакторі → Open with Live Server.
5. Якщо Live Server немає: Extensions → знайди Live Server від Ritwick Dey → Install.

Для простого перегляду можна двічі клацнути `index.html` у Провіднику. Встановлювати Node, npm чи React не потрібно.

## Що є в проєкті

- `index.html` — головна з холодильником і трьома кроками.
- `products.html` — порожня форма продуктів.
- `example.html` — заповнений приклад форми.
- `recipes.html` — два готові рецепти.
- `no-purchases.html` — варіант без докупки.
- `recipe.html`, `recipe-no-oil.html` — склад та інструкція приготування.
- `loading.html`, `input-error.html`, `no-results.html`, `service-error.html` — демонстраційні стани.
- `feedback.html`, `thanks.html` — демонстрація відгуку та підтвердження.
- `css/style.css` — усі наші стилі, розділені коментарями.
- `assets` — локальні зображення, шрифти й іконки. Інтернет для них не потрібний.
- `before` — навчальна версія головної на div для порівняння рефакторингу.

## Що працює

Переходи між сторінками, посилання меню, мобільне меню через details, перевірка required/min/max браузером. На сторінці продуктів порожній холодильник відчиняється автоматично; після введення продуктів кнопка підтвердження показує анімований приклад наповненого холодильника. Форма зберігає продукти, бюджет і фільтри під час переходів; посилання «Змінити продукти» повертають до тієї самої анімованої сторінки. На головній і сторінці продуктів можна ввімкнути звуки холодильника; звук кліку працює для кнопок та основних CTA-посилань на сторінках. Браузер може вимагати явного кліку для відтворення звуку. Клавіша Tab показує фокус.

## Що поки демонстраційне

Це HTML/CSS-каркас ЛР5. Рецепти прописані в HTML. Умови форми не обчислюються, введений список продуктів не визначає вміст анімованого холодильника, бюджет не фільтрує результати. Введені продукти та бюджет передаються через сторінку завантаження на результати й показуються там тегами; сам демонстраційний набір рецептів не змінюється. Відгук нікому не надсилається. На головній CSS-анімація автоматично відчиняє холодильник, вмикає світло, опускає холодну пару й послідовно оживляє продукти; на сторінці продуктів використовується та сама анімація з фото порожнього холодильника, але без продуктів, а кнопка підтвердження перемикає його на анімований приклад наповненого холодильника. JavaScript обробляє передавання форми між сторінками та перемикання стану анімації.

## Що самостійно доробити для здачі за методичкою

1. Налаштувати й показати AI Chat у своєму VS Code; знімок встановлених розширень.
2. Зробити скриншот HTML (header/main/footer) і :root з редактора.
3. Зробити скриншот ПК та телефона через Chrome DevTools.
4. Перевірити HTML через https://validator.w3.org/nu/ — завантажити фінальний index.html. Онлайн-перевірку цієї нової версії ще не зафіксовано.
5. Виконати власні запити з PROMPT-LOG.md у VS Code, зберегти фактичні відповіді.
6. Оформити PDF-звіт із титулкою, скриншотами, промптами й висновком. Цей архів містить код, а не готовий звіт.
