# Як пояснити код простими словами

HTML — зміст і структура. CSS — оформлення й розташування. Тут немає фреймворків і JavaScript.

`header` — шапка з логотипом. `nav` — посилання меню. `main` — основний вміст; один на сторінку. `section` — тематичний розділ із заголовком. `article` — окрема картка рецепта. `aside` — додаткова інформація про докупку. `footer` — підвал. `div` залишений там, де потрібне лише групування для сітки.

`h1` — головний заголовок, один на сторінку. `h2` — розділи. `h3` — підрозділи або кроки.

`a href` переходить на сторінку чи до секції. `button type="submit"` відправляє форму. `label for="budget"` пов'язаний із `input id="budget"`. `required` не пропускає порожнє поле. `min="0"` не дозволяє від'ємний бюджет.

`details` і `summary` відкривають мобільне меню без коду JavaScript. `alt` описує значущу картинку; порожній alt приховує декоративну від скрінрідера.

`:root` зберігає спільні змінні. Наприклад, `--color-green` — зелений колір, `var(--color-green)` підставляє його в правило. `@font-face` підключає наші локальні шрифти. Піксельний шрифт лише в великих заголовках, звичайний — для читання.

`display: flex` вирівнює меню в рядок. `display: grid` ділить банер та рецепт на колонки. `gap` — відстань між ними. `minmax(0, 1fr)` дозволяє колонці стискатися. `box-sizing: border-box` включає рамку й внутрішні відступи у ширину.

`@media (max-width: 700px)` застосовує мобільні правила: одна колонка, компактний логотип, інше меню й фон. Фон декоративний, текст залишається HTML. Основний макет не побудований на absolute.

`:focus-visible` підсвічує елемент при керуванні клавіатурою. `:hover` — при наведенні, `:active` — під час натискання.

Рефакторинг означає покращення будови коду: навчальна версія before має div, фінальна — семантичні області. Повторювані кольори та шрифти перенесені у змінні.
