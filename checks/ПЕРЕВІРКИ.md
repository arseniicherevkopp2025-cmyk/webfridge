# Перевірено у цій версії

- 13 HTML-сторінок: локальні src/href/action, якорі, унікальні id, один main і h1, alt, цілі label — без знайдених помилок. Результат: local-checks.json.
- HTTP-відповідь локального сервера: 200.
- Головна та сторінка рецепта оглянуті в Chrome на десктопі.
- Головна, порожня форма та результати оглянуті у трьох iframe-вікнах шириною 390 px. Це перевірка media queries; це не скриншот Device Toolbar.
- Натискання submit на example.html відкрило loading.html з GET-параметрами, кнопка результату відкрила recipes.html, перший рецепт — recipe.html.
- HTML та CSS відформатовані Prettier.
- Онлайн W3C для цієї версії не виконувався. Повний аудит доступності та тестування кожної сторінки на кожній ширині не виконувались.
