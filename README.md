# Холодильник студента

Багатосторінковий адаптивний вебсервіс для планування харчування з продуктів, які вже є вдома, та з урахуванням студентського бюджету. Проєкт продовжує лабораторні роботи №6–7.

## Запуск

Сайт статичний. Відкрийте `index.html` у браузері або запустіть локальний сервер із кореня проєкту. У VS Code можна використати розширення Live Server.

## Стек

- HTML5, CSS і JavaScript
- Tailwind CSS
- YouTube embeds і Google Maps

## Сторінки

Головна сторінка — `index.html`; окремі HTML-файли демонструють каталог рецептів, сторінки рецептів, продукти, зворотний зв’язок і стани інтерфейсу.
