# Prompt Log — лабораторна робота №8

## Запит користувача

> Зробити лабораторну №8: проаналізувати завдання і виконати його повністю самостійно, якщо можливо.

## Аналіз та рішення

Умова вимагає локальний Git, віддалений публічний GitHub-репозиторій, мінімум три змістовні коміти, GitHub Pages, Netlify, посилання на розгортання, скриншот `git status`/`git log` і короткий звіт. Для проєкту налаштовано README, `.gitignore`, `netlify.toml` і `.nojekyll`.

## Дії

1. Перевірено початкову папку проєкту й скопійовано її до `Web3`.
2. Старі стартові файли `before/` виключено з публічної історії.
3. Підготовлено локальну історію та конфігурацію статичного хостингу.
4. Перевірено у браузері, що GitHub-репозиторій `webfridge` публічний.
5. `git push` через Git Credential Manager не завершився через авторизацію/TLS у середовищі.
6. Після того як користувач дозволив розширенню Chrome доступ до локальних файлів, 83 потрібні файли завантажено в GitHub web UI логічними пакетами; після фінального оновлення звіту історія матиме 14 змістовних комітів.
7. Локальну гілку `main` синхронізовано з `origin/main`; робоча директорія чиста.
8. Увімкнено GitHub Pages з `main` і `/ (root)`; автоматична збірка Pages завершилась успішно. Головна сторінка доступна за адресою https://arseniicherevkopp2025-cmyk.github.io/webfridge/.
9. Netlify GitHub login указав на вже зареєстрований акаунт. Після входу через наявний Google-акаунт GitHub authorization показав лише читання email, але кнопку підтвердження було вимкнено. Замість підключення репозиторію створено публічний Netlify-проєкт через Drop і завантажено ZIP-архів статичного сайту.
10. Production-сайт Netlify перевірено у браузері: https://peaceful-faun-db7da8.netlify.app/. Автоматичне розгортання з GitHub не налаштовано.
11. Локальні `git status` і `git log --oneline` перевірено після синхронізації. Через збій знімка вікна VS Code скриншот Source Control/терміналу до звіту ще потрібно додати вручну.
