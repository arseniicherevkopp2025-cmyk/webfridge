# Prompt Log — лабораторна робота №8

## Запит користувача

> Зробити лабораторну №8: проаналізувати завдання і виконати його повністю самостійно, якщо можливо.

## Аналіз та рішення

Умова вимагає локальний Git, віддалений публічний GitHub-репозиторій, мінімум три змістовні коміти, GitHub Pages, Netlify, посилання на розгортання, скриншот `git status`/`git log` і короткий звіт. Для проєкту налаштовано README, `.gitignore`, `netlify.toml` і `.nojekyll`.

## Дії

1. Перевірено початкову папку проєкту й скопійовано її до `Web3`.
2. Старі стартові файли `before/` виключено з публічної історії.
3. Підготовлено три змістовні коміти: імпорт сайту, налаштування/опис проєкту, звіт і журнал запитів.
4. Перевірено у браузері, що GitHub-репозиторій `webfridge` публічний і порожній.
5. `git push` зупинився на авторизації: Git Credential Manager не зміг використати доступне сховище облікових даних/TLS у середовищі.
6. Завантаження через GitHub web UI зупинилося, бо розширенню Chrome не надано доступ до локальних файлів. Налаштування безпеки не змінював.
7. Після ручного усунення одного з цих блокерів потрібно виконати push, налаштувати обидва деплої та внести їхні URL до звіту.
